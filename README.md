# Printr — Landing Page

A sleek, modern landing page for the **Printr** APK — a distributed print automation platform that connects customers with local print vendors.

## ✨ Features

- **Black & white premium theme** with Outfit + Plus Jakarta Sans typography
- **Scroll animations**, hover effects, and micro-interactions
- **Fully responsive** — mobile, tablet, and desktop
- **One-click APK download** linked directly to GitHub Releases
- **Contact section** with WhatsApp, GitHub, and email support

## 🛠 Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | React 18 |
| Build Tool | Vite 5 |
| Styling | Vanilla CSS |
| Fonts | Google Fonts (Outfit, Plus Jakarta Sans, JetBrains Mono) |

## 🚀 Quick Start

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173`

## 📦 Build

```bash
npm run build
npm run preview
```
