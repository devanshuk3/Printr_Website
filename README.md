# Printr — Landing Page

A sleek landing page for the **Printr** APK — a distributed print automation platform that connects customers with local print vendors.


## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | React 18 |
| Build Tool | Vite 5 |
| Styling | Vanilla CSS |
| Fonts | Google Fonts (Outfit, Plus Jakarta Sans, JetBrains Mono) |

## Quick Start

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173`

## Build

```bash
npm run build
npm run preview
```
